# Africa Team Hub 🌍

Single-file HTML meeting hub for Africa Team weekly online income sessions.

## What's Inside

A fully self-contained HTML file (`africa-team-meeting-hub.html`) that serves as the **command center** for all Africa Team live meetings — every Tuesday & Thursday at 8PM EAT.

## Features

- **Live Countdown** — auto-calculates time to next Tue/Thu session (EAT timezone)
- **5-Tab Meeting Agenda** — Standard session + 4 product focus rotations
- **Product Cards** — UTrading AI, Coinverse, Eropia DeFi 4.0, KindFlow with referral links
- **Telegram Section** — @africateamhub channel + @Africateambot integration
- **Presenter Dashboard** — Scripts, pre-meeting checklist, objection handlers
- **Copy-Ready Templates** — WA & Telegram invite messages for every scenario
- **60-Min Live Timer** — Segment-by-segment countdown with audio alert
- **Next Steps Roadmap** — 8 prioritised actions post-meeting
